# Evaluation design

The unit of analysis is a fixed labeled graph. For each of karate, football, Cornell, Texas and Wisconsin, evaluate depths 1, 2 and 3. Use the probability of matching endpoint labels on a stationary unweighted random walk of length 2r+1. Compare its observed value, the feasible minimum and maximum, a coordinatewise stub-pair relaxation and the span of 96 retained constrained-switch samples. Use three seeds (41, 73, 101), 20 warm-up sweeps and 32 measurement sweeps, each with one attempted update per input edge. Select eligible blocks uniformly and two different edges uniformly within a block. Use the graph as observed to initialize each chain. These are descriptive comparisons without sampling-based significance tests.

Input preprocessing retains named incident vertices, merges reciprocal links, drops loops and discards weights. Use the supplied club, conference or webpage labels without fitting. No connectedness constraint is imposed on feasible completions. Test every isolate-free labeled simple graph on five vertices with one fixed 3:2 partition and the explicit two-mark cycle construction at depths 1 through 8 before running the five cases. Recompute endpoint probabilities on both witness graphs and check every vertex's constrained counts. Record the optimality gap, software versions, code and input checksums, and witness edge lists.
